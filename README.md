# مصاريفي | قناة التحديثات العامة

هذا المستودع مخصص لإصدارات APK الموقَّعة الخاصة بتطبيق **مصاريفي**، وليس لكود المصدر أو البيانات المالية.

**أول إصدار مخطط:** `v1.0.0`، رقم البناء `1`.

**حالة التوزيع:** لا يوجد APK رسمي منشور حتى الآن. سيُنشر هنا بعد نجاح البناء والاختبارات وإعداد مفتاح توقيع Release الثابت.

تستخدم إصدارات التطبيق `GitHub Releases` للاكتشاف وعرض «ما الجديد» وتنزيل ملف APK داخل التطبيق. تأكيد التثبيت يتم عبر Android. أول تحديث بعد النسخة 1.0.0 قد يحمل `v1.0.1` ورقم البناء `2`.

للحصول على أول APK الرسمي لاحقًا، راجع [صفحة الإصدارات](https://github.com/Eslam-Salah/Masarefy-Updates/releases).
