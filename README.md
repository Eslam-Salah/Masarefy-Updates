### ما الجديد في v1.0.2؟

- إزالة المساحة الفارغة الثابتة (62dp) التي كانت تُحجز أسفل قائمة الرئيسية لزر «اسأل مصاريفي».
- الإبقاء على الزر عائمًا في أسفل يمين الرئيسية، بحجم لمس 48dp وأيقونة 22dp.
- توفير فراغ قابل للتمرير في **نهاية القائمة فقط** حتى لا يغطي الزر آخر بطاقة.
- عدم تغيير حسابات المصروفات والإيرادات، أو قاعدة البيانات أو النسخ الاحتياطية أو وظائف المعاملات.
