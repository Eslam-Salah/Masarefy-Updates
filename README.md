### ما الجديد؟

- تحسين عرض الأرقام المالية وأسماء التصنيفات والمعاملات كاملةً على الرئيسية، خصوصًا مع تكبير الخط.
- توحيد حساب عدد عمليات التصنيفات عند تقسيم معاملة إلى أكثر من بند تحت التصنيف نفسه، مع الحفاظ على المجاميع المالية.
- الإبقاء على قاعدة البيانات الحالية ووظائف المصروفات والإيرادات والنسخ الاحتياطية.
